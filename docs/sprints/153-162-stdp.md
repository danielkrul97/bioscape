# Sprinty 153–162: STDP + reward-modulated plasticity

Desítka 143-152 dodala Izhikevich infrastrukturu, ale **Izhikevich + Hebbian
stagnuje v stable-but-minor niche** (4-7 % populace cross-seed). Insight z
S152 retro: pure neuron-model switch bez timing-based plasticity používá
stejný rate-coded selekční signál → žádný fitness edge.

**Decade cíl:** dodat STDP rule (spike-timing dependent plasticity) jako
samostatný plasticity dispatch pro Izhikevich lineages. Per-synapse
eligibility trace + 3-factor reward modulation. Pokud STDP umožní
Izhikevich lineage win in some niche (predator? maze nav?), validace
ukáže že timing-based information ne-je informačně degenerovaný jako rate
brain at saturation.

## Sprint 153 — Pre-spike encoder

**Cíl:** map continuous brain inputs na binary spike events per tick.
Threshold-based encoder pro deterministic baseline; rate-coded
(Bernoulli sampling) ponecháno do follow-up.

**Výstup:** `SPIKE_ENCODE_THRESHOLD = 0.5` v `params/reproduction.rs`.
`Brain.last_pre_spike_ticks: [u32; BRAIN_INPUTS]`, `Brain.last_post_spike_ticks:
[u32; BRAIN_HIDDEN]` (oba `#[serde(skip)]` — checkpoint round-trip fresh
state, recovers v <100 ticks). `Brain::forward_izhikevich_with_state`
rozšířen o `tick: u32` parameter, encoder loop pre-tick threshold checks,
post-spike tracking inside sub-step integrator. Test call sites updated
(tick=0). Lib testy 437 passed (1 ignored). GPU shader update odložen
do S154/S155 (production cesta není ovlivněna zatím — fields existují
ale STDP rule není wired).

**Poznámky:** GPU `brain_forward_izhikevich.wgsl` zatím nepíše do spike
time buffers — Izhikevich production path běží bez STDP timing capture.
S155 přidá GPU spike-time buffers + shader update.

## Sprint 154 — Eligibility trace per synapse (CPU)

**Cíl:** alokovat per-synapse eligibility buffer + decay/accumulate logic
CPU-side. STDP timing rule používá trace místo immediate Δw.

**Výstup (revised scope — per-neuron místo per-synapse):** sprint plán
předpokládal per-synapse trace (~15 KB/cell), ale realizace per-neuron
**pre_trace** + **post_trace** je mathematicaly ekvivalentní pro STDP
rule + ~30× menší footprint (516 B/cell). `Brain.pre_trace: [f32;
BRAIN_INPUTS]`, `Brain.post_trace: [f32; BRAIN_HIDDEN]` s serde defaults
+ custom serde array modules (reused `serde_arr_inputs`,
`serde_arr_hidden`). `Brain::stdp_step(tick, tau_ticks)` decays both
traces by `exp(-1/tau)`, bumps slots whose spike-time array matches
`tick`. 1 unit test `stdp_step_decays_traces_and_records_spikes` passing.
Lib testy 438 passed (1 ignored).

**Poznámky:** STDP rule implementace v S155 použije per-neuron traces:
- On post-spike at h: `Δw[i][h] += a_plus × pre_trace[i]` (LTP)
- On pre-spike at i: `Δw[i][h] -= a_minus × post_trace[h]` (LTD)
Per-neuron trace efektivně kóduje "kdy neurony naposledy spike-ly" v
exponenciálně klesající váze, takže rule je stejně silný jako per-synapse
verze, ale šetří paměť i compute.

## Sprint 155 — STDP weight update rule (CPU)

**Cíl:** classical STDP curve — `Δw = a_plus × exp(-Δt/tau)` if pre
before post, `Δw = -a_minus × exp(-Δt/tau)` if post before pre.

**Plán:** per-cell `pre_spike_times: [u16; BRAIN_INPUTS]`, `post_spike_times:
[u16; BRAIN_HIDDEN]` (tick numbers). On pre-spike event: for each post
neuron, compute `Δt = tick - last_post_spike[h]`, apply LTD if Δt > 0.
On post-spike: walk pre neurons, apply LTP. Use genome `stdp_a_plus`,
`stdp_a_minus`, `stdp_tau_ticks` (S148 plumbing).

**Acceptance:** 2-neuron test fixture s correlated firing → w grows
(LTP confirmed). Anti-correlated → w shrinks (LTD confirmed). Lib testy
pass.

## Sprint 156 — 3-factor learning (STDP + reward)

**Cíl:** reward modulation of STDP trace (analog k S133 reward-modulated
Hebbian).

**Plán:** STDP timing → eligibility trace (S154). Reward event triggers
`Δw = lr × reward × eligibility`. Per-cell `learning_rate` (S136)
re-used pro STDP gain. Bridge funguje pro Izhikevich cells; Perceptron
cells pokračují s S133 Hebbian path beze změny.

**Acceptance:** Izhikevich cell exposed to reward streamem → weights
měřitelně diverge from random init na ticks ~300-600. CPU test +
seed=0 30-gen smoke `izhikevich_frac` ≥ pre-S156 baseline (Izhikevich
neztrácí fitness s STDP active).

## Sprint 157 — GPU STDP shaders

**Cíl:** port S154-S156 CPU rules na GPU compute.

**Plán:** `shaders/stdp_step.wgsl` (per-tick trace decay + accumulate),
`shaders/stdp_apply.wgsl` (reward apply). Mirror layout S133 hebbian
shaders. Storage budget +3 bindings (stdp_trace, pre_spike_times,
post_spike_times) — pod limit 12. Dispatch pouze pro Izhikevich cells
(neuron_models gate).

**Acceptance:** `stdp_step_gpu_matches_cpu` parity test ε=1e-3.
Production headless run nestabilní → fallback na CPU only path.

## Sprint 158 — Performance + sparse spike updates

**Cíl:** STDP walk přes všechny synapse je expensive (84×45 = 3780 ops
per spike × 8+ spikes per tick = 30K ops/cell). Sparse update s pre-spike
mask zatomatizuje hot path.

**Plán:** spike events stream místo dense matrix walk. Per pre-spike:
walk active post neurons only. Per post-spike: same. Vyžaduje per-tick
spike list buffer.

**Acceptance:** ≥ 56 ticks/s na pure-Izhikevich populace (vs 113 baseline
pure-Perceptron). Lib testy unchanged.

## Sprint 159 — Pre-seeded mixed initial population

**Cíl:** bypass slow mutation-driven bootstrap (S149 trvalo 30+ gen aby
Izhikevich frakce přesáhla 5 %). Initial 50 % cells na Izhikevich →
rychlejší niche measurement.

**Plán:** new CLI flag `--initial-izhikevich-frac=0.5`. World::new
randomly assigns `NeuronModel` per cell at gen 0. Pre-existing seed=0
runs s default 0.0 frac jsou backward-compatible.

**Acceptance:** seed=0 30-gen smoke s `--initial-izhikevich-frac=0.5`
pop survives, izh_frac trajectory measurable from gen 0.

## Sprint 160 — STDP observability

**Cíl:** CSV columns pro STDP-specific metrics.

**Plán:** new cols `stdp_trace_norm_avg` (mean |trace| per cell),
`stdp_lr_apply_count_gen` (Δw applies / gen), `synaptic_change_avg_izh`
(per-Izh-cell |Δw| sum / gen). Helper functions v csv.rs analog k S140
helpers.

**Acceptance:** 5+ nových sloupců, perf regression < 5 %.

## Sprint 161 — Cross-seed mixed-pop validation

**Cíl:** 3 seedy × 50 gen s `--initial-izhikevich-frac=0.5` + STDP active.
Compare s S149-S150 (Izhikevich + Hebbian only) — měřit jestli STDP
přinese Izhikevich-dominance OR niche divergence.

**Plán:** validation report `docs/sprints/153-162-validation.md` s
trajectorie izh_frac, lr_avg per model, predator/forager differentiation.

**Acceptance:** alespoň v 1 z 3 seedů Izhikevich frakce > 30 % v steady
state (vs ≤ 7 % bez STDP). Indicates STDP přidal fitness edge alespoň
v některém niche.

## Velká varování pro desítku

1. **STDP komplexita.** S154-S156 jsou jádrem desítky. Per-synapse trace
   + spike timing + reward modulation = ~3 paralelní state machines
   per cell. Bug-prone.

2. **GPU port (S157) high risk.** Per-synapse atomics nebo write
   contention v shader může způsobit data races. Fallback na
   CPU-only STDP acceptable.

3. **Mixed model + mixed plasticity.** Perceptron cells na Hebbian
   (S133), Izhikevich cells na STDP. Reward funnel (S134-S135) musí
   dispatchovat na obě cesty correct podle per-cell model.

4. **STDP může destabilizovat.** Anti-symmetric STDP s positive feedback
   může explodovat weights nad synaptic scaling cap. Cross-seed shock
   test (S161) je essential.

5. **Pre-spike encoder degenerate na low-magnitude signals.** S153
   threshold encoder ztrácí <0.5 inputs. Rate-coded (Bernoulli)
   encoder by zachoval info, ale přidává stochasticity → byte-identical
   asserts harder. Defer rate-coded do 163+.
