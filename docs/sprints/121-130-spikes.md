# Sprinty 121–130: Multi-spike + spike-based food gathering

Desítka přechází z perf optimalizací (S111–117) zpět k biologické rovině:
**rozšíření spike mechaniky**. Pre-Sprint-121 měla buňka jeden frontální spike
sloužící čistě jako útočná zbraň (predation bonus v ~45° kuželu). Tahle
desítka:

1. **Multi-spike** — buňka může mít až `SPIKE_SLOTS = 5` spike, každý
   s vlastním směrem (azimuth + elevation offset relative k forward) a
   geometric complexity parametrem.
2. **Spike → eat** — spike rozšíří food gathering: per-spike forward grab
   cones u tipu (Sprint 122). Pre-S122 `eat_test` (čistý ellipsoid) zůstává
   primárním testem; spike grab je opt-in zóna navíc.
3. **Geometric complexity** — continuous parametr ∈ [0, 1] s super-lineární
   cost (quadratic), lineární attack/eat bonus. Sweet-spot kolem 0.4–0.6
   (degenerate single-max-complexity příliš drahý).

Datová struktura: `Genome` i `Phenotype` drží `[Spike; SPIKE_SLOTS]` +
`spike_count: u8`. Pole je fixed (ne `Vec<Spike>`), protože `Cell` musí
zůstat `Copy` (Bevy par_iter snapshoty Sprint 113, GPU storage buffer pevný
layout).

Brain output budget zachován (BRAIN_OUTPUTS=10). Output[5] (`morph_spike`)
je aggregate signal proporčně rozdělený přes všechny aktivní spiky podle
length. Spike orientation + complexity = pure-genetic (mutace v `Genome`,
žádný runtime morph). `spike_count` je discrete add/remove na reprodukci.

## Sprint 121 — datová struktura ([Spike; 5]) byte-identical refactor

**Cíl:** zavést `Spike` struct, `spikes: [Spike; SPIKE_SLOTS]` a `spike_count: u8`
v `Genome` i `Phenotype` jako náhradu pre-S121 `spike_length: f32`. Žádná
změna chování — gen 0 cells dostávají `spike_count = 1`, primary spike
length z původního `random_range(0..0.1)`, ostatní spike fieldy zero.
Acceptance: `seed=42 30-gen` headless byte-identical s pre-S121 (kromě
`ticks_per_sec` perf metriky).

**Výstup:** `Spike` (length / azimuth / elevation / complexity) + `SPIKE_SLOTS=5`
const + complexity multiplikátory (`COMPLEXITY_ATTACK_GAIN`, `COMPLEXITY_COST_GAIN`,
`COMPLEXITY_GRAB_GAIN`) připravené pro S122/123. `Phenotype::primary_spike_length`,
`total_spike_length`, `active_spikes` helpery. `Cell::spike_bonus_against`
iteruje per-spike s direction-aware cone testem (`spike_direction(yaw, pitch, &spike)`).
`apply_energy_costs` sumuje spike maintenance přes aktivní sloty. RNG ordering
zachované v `Genome::random` / `mutate` / `crossover` přes short-circuit pattern
(jako Sprint 82 `vision_fov`). Test fixtures + `mutation_with_zero_sigma_is_identity`,
`spike_bonus_*`, `morph_*` testy migrované na nový layout. Headless +
renderer + GPU aux upload čtou přes `primary_spike_length()` (single-spike
sémantika v S121 zachovaná).

**Poznámky:** byte-identity ověřená diffem bez `ticks_per_sec` sloupce
(wallclock noise). 171 lib testů zelených. GPU shader path beze změny —
`primary_spike_length()` produkuje stejný `aux[0]` jako pre-S121
`phenotype.spike_length`.

## Sprint 122 — multi-spike biology + per-spike eat cones (CPU only)

**Cíl:** zapnout `spike_count_mutation_rate = 0.05` + `sigma_spike_orientation = 0.05`
+ `sigma_spike_length_secondary = 0.03`. Per-spike grab cones u tipu spike
(`Cell::eat_test_with_spikes`). Predate cyklus iteruje per-spike přes
`spike_bonus_against` (S121 multi-spike-aware). GPU path zachován pro
single-primary-spike sémantiku (Sprint 124 je multi-spike GPU).

**Výstup:** `eat_test_with_spikes` testuje ellipsoid first, pak per-spike
grab kuželky u tipu (`tip = pos + dir × (eff_r + length)`, half-angle
`SPIKE_GRAB_HALF_ANGLE × (1 + complexity × COMPLEXITY_GRAB_GAIN)`, range
`length × SPIKE_GRAB_REACH_BONUS`). `try_eat` přepnuto na nový test.
`Genome::mutate` zahrnuje per-slot length/orientation drift + discrete
spike_count ±1 mutaci (rate 0.05). Crossover per-slot multi-attribute
(short-circuit pokud parents shodné, takže S121 zero-config zůstává byte-
identical). Headless `predate` smyčka teď používá `spike_bonus_against`
přímo (multi-spike-aware).

**Poznámky:** seed=42 30-gen smoke: pop 200 → 1020 (gen 30, baseline 1028
v S121, drift v rámci očekávaného mutation noise). spk_avg roste 0.051
→ 0.394 (primary spike length, ne total — observability rozšíření přijde
v S125). Žádná extinkce. 171 lib testů zelených. Trajectory rozjeta od
S121 (expected — nové RNG draws v `Genome::mutate` per spike_count + per-slot
attributes).

## Sprint 123 — geometric complexity tradeoff

**Cíl:** zapnout `sigma_spike_complexity = 0.02` (2 % range/gen drift) +
scaled morph rate pro high-complexity spike (`rate_factor = 1 - 0.5 × complexity`).
Acceptance: stabilní pop, complexity drift k intermediate hodnotám
(unimodal kolem 0.2-0.6).

**Výstup:** `apply_spike_morph` per-slot `rate_factor` škálování — high-complexity
spike je commitment, nemůže rapid morphovat length. Quadratic cost
multiplikátor (`COMPLEXITY_COST_GAIN = 3.0` → max-complexity ×4 cost) +
lineární attack/grab bonus aktivní (Sprint 122/123 helpery byly připravené).

**Poznámky:** seed=42 30-gen smoke: pop 200 → 1248 (gen 15 mid-run). Pop
oscilace 633-1497 reflectuje multi-spike + complexity selekční hledání
sweet-spotu. 171 lib testů zelených. Smoke S123 nedokončený full 30-gen
(time-limit), Sprint 125 cross-seed validation finalizuje complexity
distribution check.

## Sprint 124 — GPU parita (multi-spike upload, single-direction approximation)

**Cíl:** GPU step shader (`step.wgsl`) musí drainovat energii konzistentně
s CPU multi-spike (sum × complexity_factor × cost_per_sec). GPU predate
shader (`predate.wgsl`) neuvidí multi-direction, ale primary spike musí
respektovat complexity attack factor.

**Výstup:** `Phenotype::total_spike_cost_factor()` (sum length × cost_factor
across active) + `primary_spike_attack_factor()` (slot 0 length × attack_factor)
helpery. Aux upload v headless + gpu.rs aux mapping změněn:
`aux[0] = total_spike_cost_factor` (pre-multiplied complexity-aware sum).
Step shader unchanged — `aux[0] × spike_cost_per_sec × dt_eff` matchne CPU
sum exactly. `step_gpu_matches_cpu` parity test passes (ε=1e-4). PredateGpu
production path není v headless ani rendereru (CPU-only); test
`predate_gpu_matches_cpu` zachovává single-spike fixture.

**Poznámky:** Multi-spike non-primary slot direction-aware predate je
**CPU-only** (Sprint 122). GPU predate by full multi-spike vyžadoval
shader rewrite (per-spike storage buffer + variable-length loop) + pitch
inputu — odložené pro Sprint 126+ pokud production benchmark vyžaduje.
Sprint 124 zachovává step shader correctness pro `--gpu-full` headless
(brain/sensor/collision na GPU, predate na CPU).
