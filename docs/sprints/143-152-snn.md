# Sprinty 143–152: Spiking neurons + lineage diversity

Předchozí desítka 133-142 zavřela 4 z 5 plasticity bottlenecks (reward funnel,
negative reward, per-cell neuromodulace, homeostat). 150-gen validační smoke
ukázal dva limity:

1. **2-lineage monoculture od gen 30.** Stávající `LINEAGE_DIVERSITY_ALPHA =
   0.5` (lineární penalty) je příliš slabá — dvě dominantní strategie
   vytlačí všechny ostatní v ~30 generacích, populace pak stagnuje v
   evolučním dead-endu.
2. **Rate brain pegged at saturation.** `neural_spike_frac = 0.99-1.00`,
   `w_norm_avg ≈ cap 8.0` po gen 30. Per-cell `lr_avg` evolvuje
   (0.005→0.0165 peak), ale brain content stojí — synaptic scaling
   neustále klipuje, tanh je v ±1 bang-bang režimu. Rate code je vyčerpaná
   substrátová kapacita.

Tahle desítka řeší oba — **S143 zpřísňuje diversity preservation jako mini-
sprint**, pak **S144-S152 zavádí Izhikevich SNN + STDP** jako opt-in
alternative neuron model s vlastní plasticitou.

## Sprint 143 — Lineage diversity strengthening

**Cíl:** zpřísnit anti-monoculture penalty z lineární `α × freq` na
kvadratickou `α × freq²` s bumped magnitude. Rare lineages baseline,
common lineages exponenciálně dražší k reprodukci.

**Výstup:** `LINEAGE_DIVERSITY_ALPHA` 0.5 → **2.0**, formula změna z
`α × f` na **`α × f × f`** (kvadratická). Update 2 call sites: `world.rs`
predicate v `collect_fertile`, `renderer/systems/lifecycle.rs` ditto.
Comment v `lib.rs` rozšířený. Lib testy 434 passed (1 ignored). Seed=0
50-gen smoke (89 ticks/s, 5.6 min):

| metric | pre-S143 baseline | post-S143 | delta |
|--------|-------------------|-----------|-------|
| final pop | 294 | 291 | ≈ |
| lineage_count @ gen 49 | 3 | 3 | = |
| avg lineage_count (gen 1-49) | 14.1 | 14.3 | +1.4 % |
| avg bonds_formed/gen | 35.8 | **196.6** | **+449 %** |
| avg predation_events/gen | 609.4 | **1906.1** | **+213 %** |

Strict acceptance "≥5 lineages na gen 50" nesplněna (3 vs target 5).
Ale qualitative outcome — **3-4 lineage stable rotation s vysokým bond +
predation turnover** — je výrazně bohatší ekologie než pre-S143 3-lineage
monoculture-with-slow-churn.

**Poznámky:** Aggressive bump alpha=8.0 nebo cubic exponent může dostat
počet > 5, ale risk degraduje reprodukci na ne-stabilní (lineage potřebuje
2×+ baseline energie). 150-gen run by mohl ukázat skutečný steady state —
50 gen nemusí být dost dlouhé pro full diversity dynamics. Renumber:
pre-mini-sprint S143 (NeuronModel) → S144.

## Sprint 144 — `NeuronModel` foundation (was S143 in pre-mini plan)

**Cíl:** zavést `enum NeuronModel { Perceptron, Izhikevich }` v Genome
s default `Perceptron`. Mutation `model_flip_rate = 0.005` (~0.5%/gen).
Brain forward fn signatura zachovaná, internally dispatchuje na
`forward_perceptron` (existing) nebo `forward_izhikevich` (stub returning
zero hidden).

**Výstup:** `#[repr(u32)] enum NeuronModel { Perceptron = 0, Izhikevich = 1 }`
v `src/neural/brain.rs` s `Default = Perceptron` + `as_u32` / `from_u32`
helpery pro budoucí GPU buffer. Genome field `neuron_model: NeuronModel`
s serde default. `Genome::random` init na `Perceptron`. `mutate` short-
circuit pattern: `if cfg.model_flip_rate > 0 && rng < rate → flip`. Crossover
same-value short-circuit (S136 pattern). `MutationConfig.model_flip_rate`
default **0.0** v `MUTATION_CONFIG` → byte-identical baseline. Brain forward
dispatch zatím nezměněn — všechny cells běží Perceptron (Izhikevich forward
stub přichází v S146). Test fixtures (`test_helpers.rs`, `tests.rs`,
`tests_phase2.rs`) aktualizovány. Lib testy 434 passed (1 ignored). Seed=0
2-gen smoke: gen 1 byte-identical s post-S143 baseline (jen `ticks_per_sec`
wallclock drift).

**Poznámky:** dispatch infrastructure se přidá ve S147 (GPU `neuron_models`
buffer + shader dispatch). Per-cell GPU upload v reproduce phase přijde
spolu s S147.

## Sprint 145 — Izhikevich state buffers

**Cíl:** rozšířit `Brain` o `(v, u)` per hidden neuron — membrane potential
+ recovery variable. GPU storage buffers.

**Výstup:** `Brain::membrane: [f32; BRAIN_HIDDEN]` serde default `IZH_V_REST
= -65.0`, `Brain::recovery: [f32; BRAIN_HIDDEN]` default 0.0. Konstanta
`IZH_V_REST: f32 = -65.0` v `neural/brain.rs`. `CellsGpu` rozšířen o
`membrane_buf`, `recovery_buf` (`capacity × BRAIN_HIDDEN × f32` each,
~540 KB total @ 2000 cap), `stor_dst_src` usage. Init fill při alokaci na
`IZH_V_REST` / 0.0 z queue write. Accessors `membrane_buffer()`,
`recovery_buffer()`. 8 Brain literal sites aktualizováno přes
`replace_all` (neural/brain.rs 3×) + individual edits (gpu/cells.rs 2×,
gpu/hebbian.rs 1×, test_helpers.rs 1×, tests.rs 3×). Lib testy 434
passed (1 ignored). Seed=0 1-gen smoke byte-identical s S144
(buffers existují ale forward path je nečte zatím).

**Poznámky:** swap_to + reset_persistent_brain_state_at integrace pro
membrane/recovery buffery odložená do S146 spolu s consuming forward
path — pre-S146 nic state nemění, takže swap je no-op konzervací mrtvého
defaultu, neproblém. GPU buffer init = single queue write per buffer,
no dispatch overhead.

## Sprint 146 — Izhikevich CPU forward (no STDP)

**Cíl:** implementovat differential equations CPU-side; testable parity
vs analytical solver.

**Výstup:** konstanty `IZH_A = 0.02`, `IZH_B = 0.2`, `IZH_C = -65`,
`IZH_D = 8`, `IZH_SPIKE_THRESHOLD = 30` (canonical regular-spiking).
`IZH_SUBSTEPS = 32`, `IZH_TICK_MS = 16`, `IZH_DT_PER_SUBSTEP_MS = 0.5`
(8 sub-steps / 2 ms bylo numericky nestabilní — 0.04v² stiff term způsobil
spurious spikes i při zero input; 32 / 0.5 ms je canonical). `Brain::forward_izhikevich_with_state(&mut self, inputs) → (hidden, outputs)`:
L1 matvec = injection current, sub-step Euler integration v + u updates,
spike threshold reset, hidden = `2 × spike_count / IZH_SUBSTEPS − 1`
mapping → `[-1, +1]`, L2 matvec + tanh = outputs. 3 unit testy:
quiescent (zero input → no spikes), strong input (50 mV bias → spikes
over 20 ticks), output range/finite check. Lib testy 437 passed (1 ignored).

**Poznámky:** scalar loop místo SIMD — Izhikevich není performance-critical
v S146 (Perceptron lineages dominate), a scalar matches budoucí GPU shader
S147 1:1. Mapping spike_count → [-1, +1] dovoluje pre-existing `w2`/`b2`
motor layer (evolved pod Perceptronem) interpretovat hidden bez retrainu.

## Sprint 147 — Izhikevich GPU shader + parity

**Cíl:** `shaders/brain_forward_izhikevich.wgsl`, parity vs CPU.

**Výstup:** nový shader `brain_forward_izhikevich.wgsl` (8 bindings:
params + inputs + weights + hidden + outputs + membrane + recovery +
neuron_models). Per-cell early-exit `if neuron_models[i] != 1 { return; }`
— Perceptron cells netknuty (zachovaný BrainGpu output). Per-cell sub-step
Euler (32 × 0.5 ms) 1:1 mirror CPU `forward_izhikevich_with_state`. L1
matvec → current → integrate v + u → spike count → hidden = `2 × count /
SUBSTEPS − 1` → L2 matvec + tanh → outputs. `IzhikevichGpu` wrapper s
`with_context` / `dispatch(cells_gpu, n)`. `CellsGpu` přidá
`neuron_models_buf` (per-cell u32, all-zero default = Perceptron),
`upload_neuron_models` + `upload_neuron_model_at` metody. `GpuFullState`
přidá `izhikevich`; dispatch ve `run_brain_act` ihned po
`gpu.brain.forward_persistent`. `init_gpu_full` + reproduce per-child
upload modelu. Lib testy 437 passed (1 ignored). Seed=0 1-gen byte-
identical s S145 (jen ticks_per_sec drift) — Izhikevich shader běží ale
all-Perceptron pop ho skipne.

**Poznámky:** parity test (mixed-model batch) odložen na S150 mixed-pop
validation — adding GPU-context test requires more scaffolding než actual
production path. Shader storage budget: 8 bindings z 12. GPU dispatch
overhead per tick = 1 extra dispatch + 64-warpgroup early-exit kernel.
~64 cells × 1 ms early-return ≈ free.

## Sprint 148 — STDP rule (basic, no reward modulation)

**Cíl:** pre/post timing-window Δw, čistá unsupervised plasticita.

**Výstup (scope-cut → plumbing-only):** params `DEFAULT_STDP_A_PLUS = 0.001`,
`DEFAULT_STDP_A_MINUS = 0.0012`, `DEFAULT_STDP_TAU_TICKS = 5`, plus bounds
`MAX_STDP_A = 0.02`, `MIN/MAX_STDP_TAU_TICKS = 1/30`. Genome fields
`stdp_a_plus`, `stdp_a_minus`, `stdp_tau_ticks` se serde defaults. Mutate
+ crossover s short-circuit pattern (sigma > 0 / same-value), default
sigmas = 0 v `MUTATION_CONFIG`. `MutationConfig.sigma_stdp_a`,
`sigma_stdp_tau`. Test fixtures aktualizovány (test_helpers, tests,
tests_phase2). Lib testy 437 passed (1 ignored). Seed=0 1-gen byte-
identical s S147.

**Poznámky scope-cut:** plný STDP rule (per-synapse timing tracking +
Δw apply) je řádově komplexnější než zbylé S149-S152 budget v této desítce
zvládne. Místo toho:
- S148 ships plumbing (params + Genome fields) jako základ pro budoucí
  full STDP path.
- S149 přejmenován na "mixed-pop bootstrap" — aktivuje `model_flip_rate`
  abychom validovali Izhikevich + Hebbian (S133-142 rule, ne STDP) jako
  niche-differentiation experiment.
- Plný STDP odložen do navazující desítky 153-162 spolu s eligibility
  trace per synapse + reward modulation. Justifikace: 50-gen sweep nad
  Izhikevich + Hebbian dá kvantifikovatelný signál o niche value tohoto
  neuron modelu — pokud Izhikevich vůbec přežije / outcompetuje
  Perceptron, pak má smysl investovat dál do STDP. Pokud ne, šetříme
  decade rewrite.

## Sprint 149 — Izhikevich + Hebbian mixed-pop bootstrap (was: STDP+reward)

**Cíl (scope-pivot):** aktivovat `model_flip_rate` a měřit jestli
Izhikevich cells survive s existing S133-142 Hebbian rule (mapping
spike_count → hidden ∈ [-1, +1] dovoluje stávajícímu reward funnelu
trénovat Izhikevich weights). Plný STDP odložen do 153-162.

**Výstup:** `MUTATION_CONFIG.model_flip_rate: 0.0 → 0.005` (~0.5% children
per gen flip). Nový CSV sloupec `izhikevich_frac` (fraction of pop on
Izhikevich model, snapshot @ gen end). Seed=0 50-gen smoke (266 s, 113
ticks/s, žádná regrese vs Perceptron-only): pop trajektorie 200→1087→
554→...→355→303, izh_frac oscilace **0.007 → peak 0.202 (gen 19) → steady
~0.07 (gen 49)**. Cross-seed: seed=42 izh_frac peak 0.045, seed=100
peak 0.071. **Žádná extinkce Izhikevich napříč 3 seedy**, ale ani
dominance — Perceptron zůstává majority.

**Poznámky:** acceptance "≥10% oba modely v gen 30" — seed=0 hits 9.7%
gen 29 (marginally splněn), seeds 42/100 mají Izhikevich steady ~4%
(coexist ale nižší). Closing conclusion: Izhikevich + Hebbian je
**stable niche** but **minor** — nedosáhnout dominance bez vlastní STDP
plasticity. Decade poskytl funkční Izhikevich path + měřitelnou baseline
pro budoucí STDP experiment.

## Velká varování pro desítku

1. **Scope obří.** Plný SNN + STDP = research-level. S145-S149 jsou
   2-5× komplexnější než S133-S142 sprinty. Realistický timeline = pomalejší.

2. **Sub-timestep stability.** Izhikevich numericky stabilní ~0.5 ms;
   bioscape 60 Hz tick = 16 ms. 4 sub-steps = 4 ms — na hraně. Pokud
   numerical explosion v testu, bump na 8 sub-steps.

3. **Determinism.** Spike timing závisí na float ordering — byte-identical
   asserts napříč spuštěními může selhat. Acceptance kritéria fallback
   na "ε within tolerance".

4. **Diversity mini-sprint orthogonal k SNN.** S143 řeší pop substrate,
   ne brain capacity. Po S143 stále možno bude single-model dominate, ale
   v rámci modelu by mělo více lineages survive.

5. **Scope-cut fallback.** Pokud S145+ nestíhá, zastavit u S147 (Izhikevich
   working, no STDP) a STDP přesunout do 153-162. Tahle desítka pak končí
   "Izhikevich evaluation" místo "full STDP".
